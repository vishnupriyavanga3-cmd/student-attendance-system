
# Student Attendance Portal

## About the Project
StudentHub is a student registration and record management website created using HTML, CSS, and JavaScript. It provides a simple dashboard for entering and managing student information.

## Features
- Register new students
- View student records in a table
- Edit existing student details
- Delete student records
- Validate required form fields
- Validate email and 10-digit phone number formats
- Prevent duplicate Student IDs
- Display student and registration counts
- Responsive lavender-and-white user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
student-attendance-portal/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Fill in the registration form.
4. Use the Edit and Delete buttons to manage records.

No additional packages are required.

## Important Note
This is a front-end demonstration. Student records are stored in JavaScript memory and will be cleared when the page is refreshed. A database or backend is not connected.

## Purpose
This project demonstrates basic web page structure, styling, form validation, and student record management using JavaScript.
